🧠 Architecture du Pipeline Deep Learning

1

Input Layer - 12 Features

8 paramètres climatiques d'entrée (température, pluie, humidité, vent, pression, niveau mer, jours sans pluie, humidité sols) + 4 features ingénieurées (wind_log, press_def, is_extreme_wind, sol_sature).

2

K-Fold Cross Validation (5 Folds)

Validation croisée sur 25 000 échantillons synthétiques avec Early Stopping (patience=15) pour éviter le surapprentissage. Accuracy moyenne: 98.00%.

3

Deep Neural Network Architecture

Dense MLP: 256 → 128 → 64 avec BatchNorm et Dropout (0.4, 0.3, 0.2). Activation Swish. 3 sorties Sigmoid (Inondation, Sécheresse, Ouragan).
